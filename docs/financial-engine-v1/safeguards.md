## Suggested sequence for later work

1. Review and approve this baseline specification and evidence; retain the published source reference.
2. Separately introduce the canonical CI check and freeze independent reference ownership.
3. Agree names and versions of input/annual-row/project-return/equity-return contracts; document migration policy before changing any persisted form.
4. Add semantic/invariant test coverage and boundary validation with approved tolerances, preserving exact current fixtures.
5. Make small extractions behind the facade one at a time, proving bit-equivalence where no defect is being corrected.
6. Only then add new optional business-planning capabilities, each with explicit assumptions, integration tests and a separately reviewed financial contract version if semantics change.

No schema migration, dependency upgrade, engine extraction, financial correction or functionality change is authorized by this recommendation list. Security scanning and authorized production smoke acceptance remain separate operational evidence; a numerical test pass is not a security certification.
